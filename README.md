# SPPE Delivery and Impact Tracker (Balance Scorecard BSC)

Sistem penghantaran aktiviti, semakan dan papan pemuka prestasi KPI bagi Seksyen Prestasi Produktiviti & Ekonomi (SPPE), Perbadanan Produktiviti Malaysia.

Versi langsung: https://claude.ai/artifact/3QZYfahCc31vEYQ1bE5KcS

## Kandungan

| Fail | Keterangan |
|---|---|
| `index.html` | Kod sumber penuh aplikasi (satu fail: HTML, CSS dan JavaScript). |
| `data/kpis.json` | Senarai KPI, sasaran, cara pengiraan dan pegawai bertanggungjawab. |
| `data/settings.json` | Tetapan: tarikh akhir, bilangan warga, projek semasa, penyemak. |
| `data/baseline.json` | Data asal Januari–Oktober 2026 (jumlah bulanan bagi KPI). |
| `data/acts.json` | Aktiviti projek data asal Januari–Oktober 2026 (status projek). |
| `data/projplan.json` | Pelan aktiviti setiap projek dengan status siap / belum siap. |

## Nota penting

- `index.html` menggunakan perkhidmatan runtime claude.ai (pangkalan data, log masuk pengguna, muat naik bukti, emel melalui Microsoft 365). Jika dibuka di luar claude.ai (contohnya GitHub Pages), ia hanya memaparkan mesej "Buka halaman ini dalam claude.ai".
- Repositori ini ialah **sandaran kod dan data**, dan rujukan jika sistem dipindahkan ke platform lain (contohnya Microsoft 365).
- Data dalam folder `data/` ialah salinan pada tarikh eksport. Untuk salinan terkini, guna **Tetapan → Sandaran penuh** dalam sistem.
